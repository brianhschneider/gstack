Itemized list of art asset categories to incorporate into the `/game-design` skill wizard as a future "Visual Identity" stage (Stage 4.5 or standalone stage). Currently the wizard is entirely text-based; these would add an `art_direction` object to the JSON output.

**Why:** Brian asked for this list on 2026-05-22 as a reference for extending the wizard. All three categories (component, marketing, website) are considered expected scope.

**How to apply:** When extending `/game-design`, slot component-level art at Stage 4.5 (between Theme and Rules), and add marketing + website as a Stage 6.5 or wrap-up section. The JSON doc gains an `art_direction` object.

---

## Component-level art

- Card frame / border template (ornate, minimal, sci-fi grid, etc.)
- Card back design (pattern, logo placement, color)
- Card illustration style (ink + watercolor, pixel art, photorealistic, etc.)
- Token / pawn silhouette (shape, material feel, color coding per faction/player)
- Board / tile visual style (top-down map, isometric, abstract grid)
- Dice face design (standard pips, custom icons, engraved vs. printed)

## System-level art

- Color palette (primary, accent, background — per faction or card type)
- Icon set (action icons, resource icons, status markers — one consistent style)
- Typography (display font for headings, body font for card text)
- Game logo / wordmark treatment (serif/display, hand-lettered, emblem-based)

## Box / key art

- Key art concept (hero image — scene, characters, mood)
- Box cover composition (portrait vs. landscape, character-forward vs. scene)
- Rulebook diagram style (isometric examples, flat infographic, hand-drawn)

## Marketing assets (expected)

- Social card / announcement graphic (16:9 and 1:1 crops)
- Kickstarter / crowdfunding banner and campaign header
- Print-and-play PDF cover page
- Sell sheet (1-page B2B overview for distributors/retailers)
- Trailer / promo video thumbnail and key frame stills
- Press kit hero image + product mockup shots (box, cards fanned, board setup)
- Convention booth signage / banner

## Website assets (expected)

- Homepage hero image / banner
- Game logo lockup (horizontal + stacked variants, on dark + on light)
- Screenshot / gameplay photo gallery images
- Favicon and app icon (32px, 180px, 512px)
- Open Graph / Twitter card image (1200×630)
- "How to play" diagram illustrations
- Character / faction art for lore pages
- Newsletter header graphic
